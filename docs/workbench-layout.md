# Optional Workbench layout (web)
Default is Classic, selected in Settings > 介面版型. Layout preference is stored under portfoliopilot:layout independently of theme and portfoliopilot:v1 financial state. No data migration, no reset, no server.
- Today: real local NAV chart with visible dynamic axis, cash/cost/unrealized P&L, data warnings, daily drivers, account and allocation disclosures.
- Assets: holdings compact rows, full edit/delete/research actions, performance/report, allocation targets/ETF look-through, risk.
- Explore: direct market/revenue/valuation/events/scanner/stock/ETF/lab tools; stock sub-tabs, selected security official events.
- Watch: existing CRUD and conversion to holding, watch-scoped decision scanner.
- Records: existing trade/cash ledger, dividends and journal.
- Settings, global search, all old themes, native deep links and existing Classic behavior retained.
No paid dependencies, simulated market data, new predictive scores or new scheduled jobs. Existing chart and research modules are reused; this is not a new market data engine. No background personalized web push.
Browser regression covers Classic baseline, layout/theme persistence and unchanged financial state, both mobile and desktop widths, five navigation routes and stock tabs. User can opt out instantly.
